Authorization rules:

ADMIN:
- Can view all organizations.
- Can view all emergencies.
- Can view all resources.
- Can view and coordinate all assignments.
- Can modify/approve system-wide operational data where authorized.
- Can manage organizations and organization users.
- Can access simulations and system analytics.

ORGANIZATION_ADMIN:
- Can manage their organization's operational data.
- Can manage their organization's resources/personnel where authorized.
- Can see assignments involving their organization.
- Can report incidents and operational changes.
- Cannot modify another organization's data.
- Cannot change system-wide policies unless explicitly authorized.

ORGANIZATION_OPERATOR:
- Can update operational status.
- Can acknowledge assignments.
- Can report field observations/incidents.
- Can update assigned resources.
- Cannot manage organization users or organization configuration.

Never rely only on frontend route protection.
The backend must enforce authorization as well.
